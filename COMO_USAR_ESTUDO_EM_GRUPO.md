# Como Usar o Estudo em Grupo

## Recurso Premium
O Estudo em Grupo é um recurso exclusivo para usuários **Premium**.

## Como Funcionar

### 1. Criar uma Sala
1. Acesse o Dashboard e clique no card **"Estudo em Grupo"**
2. Clique em **"Criar Sala"**
3. Escolha a quantidade de questões (25-100)
4. Clique em **"Criar Sala"**
5. Compartilhe o código de 6 caracteres com seus amigos

### 2. Entrar em uma Sala
1. Acesse o Dashboard e clique no card **"Estudo em Grupo"**
2. Clique em **"Entrar em Sala"**
3. Digite o código de 6 caracteres que você recebeu
4. Clique em **"Entrar"**

### 3. Durante o Estudo
- Todos os participantes respondem as **mesmas questões**
- Cada um no seu **próprio ritmo**
- Veja o **progresso em tempo real** de todos os participantes
- As questões são **fixas por sala** - todos fazem o mesmo simulado

### 4. Ao Finalizar
- Quando terminar todas as questões, você verá:
  - **Ranking dos participantes** por número de acertos
  - **Percentual de acerto** de cada um
  - **Comparação de desempenho**

## Importante
- O host (criador) pode fechar a sala a qualquer momento
- Salas abertas ficam disponíveis para novos participantes entrarem
- Cada participante tem seu próprio tempo e pode revisar as justificativas

## Tabelas Necessárias no Banco de Dados
Execute o script `scripts/create-group-study-system.sql` no Supabase Dashboard:
1. Acesse seu projeto no Supabase
2. Vá em **SQL Editor**
3. Cole o conteúdo do arquivo
4. Clique em **Run**

## Funcionalidades
✅ Criação de salas com código único  
✅ Múltiplos participantes por sala  
✅ Questões sincronizadas (mesmas para todos)  
✅ Progresso em tempo real  
✅ Ranking final por desempenho  
✅ Cronômetro individual  
✅ Sistema de respostas com justificativas
