# Guia de Uso - Revisão Inteligente Combinada

## 🎯 Como Começar

### 1. Acessar a Página de Revisão
- Clique em "Revisão Inteligente" no dashboard ou menu
- Você será levado para `/review`

### 2. Escolher o Modo de Revisão

Você verá 3 opções principais:

#### **Revisão Inteligente Combinada** ⚡ (Recomendado)
- Combina questões e flashcards
- Prioriza itens mais difíceis
- Intercala tipos de conteúdo
- Mostra preview de cada item antes de começar

#### **Questões Erradas** ❌
- Organize por tema
- Revise apenas questões que você errou
- Veja explicações para cada uma

#### **Flashcards Errados** 📚
- Organize por matéria (Premium)
- Revise apenas flashcards que você errou
- Modo clássico ou com múltiplas opções

## 💡 Durante a Revisão Combinada

### Interface

```
┌─────────────────────────────────────┐
│ [← Voltar]  ✓ 3    ✗ 2              │
├─────────────────────────────────────┤
│ ████████░░ 8 de 12                  │
├─────────────────────────────────────┤
│ [🧠 Flashcard] Clínica Médica       │
├─────────────────────────────────────┤
│                                     │
│     Pergunta do flashcard           │
│                                     │
│     (Clique para ver resposta)      │
│                                     │
├─────────────────────────────────────┤
│ [ Errei ]  [ Acertei ]              │
└─────────────────────────────────────┘
```

### Flashcards

1. **Leia a pergunta (frente)**
2. **Clique no card para revelar a resposta (verso)**
3. **Escolha:**
   - ✓ **Acertei** - Você respondeu corretamente
   - ✗ **Errei** - Você não soube a resposta

### Questões

1. **Leia o enunciado**
2. **Escolha uma das alternativas (A, B, C, D, E)**
3. **Clique "Confirmar Resposta"**
4. **Veja a feedback:**
   - ✓ Resposta correta (em verde)
   - ✗ Resposta errada com a correta indicada
   - 📖 Leia a explicação
5. **Clique "Próxima"**

## 📊 Ao Final da Revisão

Você verá:
- **Total** de itens revisados
- **Acertos** em verde
- **Erros** em vermelho
- **Taxa de aproveitamento %**
- Barra visual de desempenho

### Opções:
- 🔄 **Revisar Novamente** - Faz outra sessão com os mesmos itens
- ← **Voltar** - Retorna à visão geral

## 🧠 Como Funciona o Sistema Inteligente

### Algoritmo SM-2

O sistema usa um algoritmo científico que:

1. **Prioriza o difícil** - Itens que você erra aparecem mais frequentemente
2. **Adapta o intervalo** - Itens que você acerta aparecem com menos frequência
3. **Calcula a facilidade** - Cada item tem um "fator de facilidade"

### Próxima Revisão

Após responder:
- ✓ Acertou → Intervalo aumenta (voltar em 3-7 dias)
- ✗ Errou → Intervalo volta para 1 dia

## 💡 Dicas Importantes

### ✅ Faça
- Revise regularmente (idealmente diariamente)
- Não pule itens vencidos
- Leia as explicações das questões
- Tente responder antes de clicar para revelar

### ❌ Evite
- Marcar como "correto" se não tem certeza
- Revisar apenas o que é fácil
- Deixar itens vencidos acumularem
- Revisar quando cansado

## 📈 Acompanhar Progresso

### Na Dashboard
- Veja quantos itens estão vencidos

### Na Smart Review Section
- Veja preview dos próximos itens
- Confira temas/matérias dos itens

### Ao Final da Sessão
- Confira sua taxa de aproveitamento
- Veja evolução ao longo do tempo

## 🔄 Exemplos de Fluxo

### Cenário 1: Seu Primeiro Acesso
```
1. Clique em "Revisão Inteligente Combinada"
2. Selecione de 1-20 itens vencidos
3. Complete a sessão
4. Próximo acesso será em 24 horas (novos itens)
```

### Cenário 2: Você Erra uma Questão
```
1. Questão aparece como errada
2. Vê a resposta correta + explicação
3. Próxima revisão agendada para 1 dia
4. Questão reaparece amanhã com prioridade
```

### Cenário 3: Você Acerta Tudo
```
1. Sessão completa com 100% de aproveitamento
2. Todos os itens têm intervalo aumentado
3. Próximas revisões serão em 3-7 dias
4. Itens novos/errados serão prioridade
```

## ❓ Perguntas Frequentes

**P: Por que alguns itens aparecem mais que outros?**
R: Porque você errou ou achou difícil. O sistema prioriza para melhorar.

**P: Quantos itens devo revisar por dia?**
R: Não há limite, mas 15-20 é recomendado para consistência.

**P: Posso revisar quando quiser?**
R: Sim! Mas o sistema recomenda revisar itens vencidos primeiro.

**P: O que acontece se não revisar um dia?**
R: Nada! Os itens ficam agendados e aparecem quando voltar.

**P: Como aumento meu aproveitamento?**
R: Revise regularmente, leia explicações e estude o material.
